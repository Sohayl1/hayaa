# مشروع تطبيق أندرويد لمنصة حَيَاه (Hayaa Health Android Studio Project)

تم إنشاء هذا المشروع ليعمل مباشرة وبأعلى كفاءة داخل **Android Studio** كـ Native Android App مع دعم كامل لجميع مميزات المنصة.

---

## المميزات المدمجة في التطبيق:
1. **دعم JavaScript و LocalStorage بالكامل:** لحفظ بيانات تسجيل دخول المريض أو الطبيب والتنقل السلس.
2. **صلاحيات الموقع الجغرافي (GPS):** لفتح خريطة الصيدليات القريبة وحساب المسافة بدقة بالكيلومتر والمتر.
3. **دعم رفع المستندات والصور (File Chooser):** لرفع الروشتات الطبية، وصور العيادة والشهادات مباشرة من الكاميرا أو المعرض.
4. **زر الرجوع الذكي (Hardware Back Button):** الرجوع بين صفحات الموقع بدلاً من إغلاق التطبيق فجأة، مع إشعار عند الرغبة في الخروج.
5. **السحب للتحديث (Swipe to Refresh):** سحب الشاشة للأسفل لتحديث أي بيانات في الموقع.
6. **شاشة انتظار وفحص الاتصال (Offline Screen):** تنبيه أنيق للمستخدم في حالة عدم تشغيل السيرفر أو انقطاع الإنترنت، مع زر إعادة المحاولة (Retry).
7. **الروابط الخارجية الذكية:** فتح روابط الاتصال الهاتفي (`tel:`)، واتساب (`wa.me`)، والخرائط (`Google Maps`) في تطبيقاتها المخصصة فوراً.

## خطوات التشغيل داخل Android Studio:

### 1. فتح المشروع:
1. افتح برنامج **Android Studio**.
2. اختر **File -> Open...** (أو اضغط **Open** من شاشة البدء).
3. حدد مجلد المشروع:
   `D:\Sohayl\SOHAYL\elp\haya\hayaa_android`
4. انتظر ثواني حتى ينتهي أندرويد ستوديو من عمل مزامنة (Gradle Sync).

### 2. تحديد عنوان الخادم (Server URL):
افتح الملف:
`app/src/main/res/values/strings.xml`
ستجد السطر:
```xml
<string name="app_url">http://10.0.2.2:5000</string>
```
* **لو هتشغل على محاكي Android Studio (Emulator):**
  اترك العنوان كما هو `http://10.0.2.2:5000` (هذا العنوان يربط المحاكي بـ `localhost:5000` على كمبيوترك مباشرة).
* **لو هتشغل على موبايلك الحقيقي بسلك USB أو Wi-Fi:**
  تأكد أن الموبايل والكمبيوتر على نفس شبكة الواي فاي، واكتب IP كمبيوترك، مثلاً:
  `<string name="app_url">http://192.168.1.15:5000</string>`
* **لو رفعت السيرفر على النت (Render / استضافة):**
  اكتب رابط موقعك المباشر، مثلاً:
  `<string name="app_url">https://your-domain.com</string>`

### 3. تشغيل التطبيق أو استخراج ملف الـ APK:
* **للتشغيل المباشر:** اضغط على زر **Run ▶** (أيقونة المثلث الأخضر بالأعلى).
* **لاستخراج ملف APK للتثبيت على أي هاتف:**
  من القائمة العلوية اختر: **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**
  ستجد ملف الـ APK الناتج في:
  `app/build/outputs/apk/debug/app-debug.apk`
